# Point-model comparison

Generated by `python scripts/compare_point_models.py`. Same data, same 1712 test days
(2020-01-02 to 2026-10-23), same conformal layer and target level (95%); only the model
that produces the point forecast of five-day log volatility changes.

| Point model             | RMSE   | DM p vs ridge   | Split conformal coverage   | width   | Winkler   | ACI coverage   | width   | Winkler   |
|-------------------------|--------|-----------------|----------------------------|---------|-----------|----------------|---------|-----------|
| HAR regression          | 0.446  | 0.002           | 93.1%                      | 1.623   | 2.308     | 95.3%          | 1.874   | 2.335     |
| Ridge (production)      | 0.428  | -               | 93.3%                      | 1.596   | 2.162     | 95.0%          | 1.738   | 2.211     |
| LightGBM                | 0.471  | <0.001          | 92.4%                      | 1.710   | 2.466     | 94.9%          | 2.057   | 2.454     |
| Neural net (5 averaged) | 0.456  | <0.001          | 92.3%                      | 1.641   | 2.301     | 94.6%          | 1.831   | 2.318     |

*RMSE*: root-mean-square error of the log-volatility forecast. *DM p*: two-sided
Diebold–Mariano test of equal squared error against ridge, with 4 Newey–West lags because
5-day-ahead errors overlap. *Winkler*: interval score (width plus a penalty for misses; lower is
better).

Read it as a test of the claim that a better point forecaster gives tighter intervals at the same
coverage. Coverage should stay near the target for every model, since the conformal layer does not
care how good the forecaster is; width and Winkler show what the forecaster is worth.
